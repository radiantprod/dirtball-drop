Dirtball Drop: Terrain generation simulation (C++)


Dirtball Drop is a 2D terrain generation simulation written in C++. 
The program models “dirtball” meteor impacts across a grid based world, 
updating terrain heights using distance‑based physics and user defined parameters. 
After simulation, the program outputs both an ASCII map and a full color 
BMP image generated manually through custom bitmap header and pixel‑writing logic.
